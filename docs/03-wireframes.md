# ワイヤーフレーム

調査日: 2026-09-02

伝える内容・デザインベース・文言・アイコンは変えません。変えるのは情報の並びやすさ、タップしやすさ、モバイルでの読みやすさです。

## デザインベース（維持）

| 要素 | 現行の見え方 | 扱い |
| --- | --- | --- |
| 背景 | 黒〜深紫。夜・月のヒーロー写真 | 維持。写真は後工程で同テイスト生成 |
| ロゴ | セリフ体 `Eva.Oriental` + 金のカタカナ | 維持 |
| ナビ | 横並び、現行リンク紫ハイライト | 維持。スマホは折りたたみ |
| アイコン | EVA + 蓮の円形（ピンク / ティール） | 現行アセットを SVG/PNG で再利用 |
| アクセント | 金見出し、白本文、紫ナビ | 維持 |
| SNS | Facebook / Instagram / Twitter / ブログ | アイコンそのまま |

写真はプレースホルダ枠で実装し、生成画像が揃い次第差し替えます。

## フォーム送信フィードバック（体験・問い合わせ共通）

文言 `詳細が無事送信されました！` は、API 成功の直後には出さない。アニメーションが終わってから出す。

```
状態1  idle
  フォーム入力可 / 送信ボタン可

状態2  sending     … API のレスポンスが返るまで
  送信ボタン無効（二重送信防止）
  入力欄は触れない
  「送信している」動作（例: 円が回り続ける、または点が流れる）
  成功メッセージはまだ出さない

状態3  complete    … 2xx が返った直後
  送信動作を「完了」アニメに切り替え（例: 円がチェックになる）
  完了アニメ終了後、その演出をフェードアウト

状態4  success     … フェードアウト完了後
  `詳細が無事送信されました！` を表示
  フォームは空にするか、メッセージだけ残す

状態E  error       … 4xx / 5xx / 通信失敗
  送信動作を止める
  完了アニメは出さない
  フォームを再操作可能にする
  項目下またはフォーム上に短いエラー
```

```
[送信] ──► (sending アニメ) ── API応答 ──► (complete アニメ)
                                              │
                                              ▼
                                         フェードアウト
                                              │
                                              ▼
                                   詳細が無事送信されました！
```

失敗時は complete に進まない。sending から入力画面へ戻す。
