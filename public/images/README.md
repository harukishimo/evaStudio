# AI 画像の置き場

同じファイル名で上書きすると、サイト側の参照はそのまま使えます。

| フォルダ | 用途 |
| --- | --- |
| `backgrounds/` | 全ページ背景・装飾 |
| `home/` | HOME ヒーロー |
| `profile/` | プロフィール写真（未配置） |
| `gallery/` | ギャラリー（未配置） |
| `brand/` | ロゴ・EVA アイコン |
| `placeholders/` | 差し替え前の仮画像 |

いま入っている生成画像:

- `backgrounds/night-veil.png` — 全ページ背景（夜・月）
- `backgrounds/silk-moon.png` — フッターなどへの装飾
- `home/hero-moon.png` — HOME ヒーロー
